Easy 2-Minute Setup:

  1. Open a new Google Sheet at sheets.new.
  2. In the top menu, click Extensions → Apps Script.
  3. Delete any code in the editor, click Copy Code below, paste it, and save (Ctrl + S).
  4. Click Deploy → New deployment, choose Web app. Under "Who has access", choose Anyone, then click Deploy.
  5. Copy the Web App URL and paste it into the box below!

This connects both your website forms and this admin portal directly to your Google Sheet.
