# IndoCraft Foundry - Modern B2B Manufacturing Web Model

A modern, high-conversion B2B industrial website model for **IndoCraft Foundry (KND Tooth Point)**, manufacturer & supplier of earthmoving equipment spares, bucket tooth points, side cutters, and cast iron castings located near Naroda GIDC, Ahmedabad, Gujarat.

## Key Features & Improvements Over Legacy Sites:
1. **Modern Industrial Aesthetic:** High-contrast carbon/slate dark mode with high-visibility safety amber accents designed for heavy equipment buyers and EPC contractors.
2. **Interactive Product Showcase & Categorization:**
   - Tooth Points (JCB 3DX, CAT J-Series, Komatsu PC200 Tiger Tooth)
   - Heavy-duty Side Cutters (LH/RH)
   - Weld-on Adapters & Lock Pins
   - Custom Cast Iron & Ductile SG Iron Castings
   - Mining Wear Liners & Chocky Bars
3. **Metallurgy & Quality Assurance Specs:**
   - Optical Spectrometer alloy analysis table (C, Si, Mn, Cr, Mo)
   - Core Hardness indicators (48–52 HRC) & impact energy ratings
   - 4-step QA inspection protocol
4. **Direct Conversion & B2B Lead Generation:**
   - Instant RFQ (Request for Quote) with auto-fill from individual product inquiry buttons
   - One-click WhatsApp fast inquiry direct connection
   - Digital 2026 Product Catalogue Modal
   - Brand compatibility quick grid (JCB, CAT, Komatsu, Hitachi, Hyundai, Volvo, Doosan)

## Files:
- `index.html`: Complete semantic HTML5 structure with Tailwind CSS & Lucide Icons.
- `styles.css`: Custom industrial styling, scrollbar, and filter states.
- `app.js`: Tab filtering, quote form handling, and modal triggers.

## How to Run / Preview:
Open `index.html` in any browser or launch a simple local HTTP server:
```powershell
# From the project directory:
python -m http.server 8080
# Open http://localhost:8080 in your browser
```
